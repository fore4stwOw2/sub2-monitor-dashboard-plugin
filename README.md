# Sub2 异常热力矩阵

飞书多维表格仪表盘自定义插件。它把任意两个分组字段和可选数值字段交给仪表盘宿主聚合，并用 ECharts 绘制热力矩阵。

```bash
npm install
npm run dev
```

非飞书宿主环境会显示合成样例数据，不包含真实业务记录。构建产物：

```bash
npm run build
```

`dist/` 部署到公开 HTTPS 静态地址后，在飞书仪表盘“添加组件 → 插件”中填入该地址。插件通过飞书 Host API 读取当前 Base 数据，不读取外部服务，也不包含凭据。

配置要求：

- 可自由选择数据表、数据范围、纵向分组和横向分组。
- 数值字段留空时按记录数统计；选择数字字段时按该字段求和。
- 当前仪表盘中的组合：
  - `异常明细`：`模型 × 账号`，按记录数
  - `异常明细`：`种类名称 × 分析层级`，按记录数
  - `异常明细`：`发生时间 × 状态码`，按记录数；发生时间在插件内按天聚合
