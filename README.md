# Sub2 异常热力矩阵

飞书多维表格仪表盘自定义插件。它把 `异常明细` 的“模型”和“账号”作为两个分组字段，通过仪表盘宿主 API 读取聚合数据，并用 ECharts 绘制热力矩阵。

```bash
npm install
npm run dev
```

非飞书宿主环境会显示合成样例数据，不包含真实业务记录。构建产物：

```bash
npm run build
```

`dist/` 部署到公开 HTTPS 静态地址后，在飞书仪表盘“添加组件 → 插件”中填入该地址。插件通过飞书 Host API 读取当前 Base 数据，不读取外部服务，也不包含凭据。

配置要求：

- 数据表选 `异常明细`
- 数据范围选“全部数据”或需要的视图
- 纵向分组选 `模型`
- 横向分组选 `账号`
